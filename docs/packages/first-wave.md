# Engine contract foundations

The active engine retains explicit IR/intent/protocol v1, legacy edit replay,
independent property opacity/locks, provenance, typography resets, strict selectors,
JSONC and bounded includes, quantized contrast solving and transactional final
requirements. Color/import/revision/provider/protocol failures are separately tested.

Artifact writes are atomic per file, private at creation, and reject symbolic links
and output-path collisions. Multi-artifact rollback is not promised. Domain outcomes
can be partial/refused/infeasible without a transport error.

Editor adapters, editor emission, real-editor roundtrip tests and editor-specific
packaging were removed for the engine-first playground scope. Prior implementation
is in Git history; it is not part of the current deliverable or CI.

Current verification and limitations live in `docs/IMPLEMENTATION_STATUS.md`.
Representative scope resolution is not full TextMate parsing. Human preferences,
blind interpretation annotations and real runtime rendering remain separate,
uncompleted evidence gates.
